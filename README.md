# Fieldkit: awesome OSINT tools for Windows

A curated list of the Fieldkit family — open-source intelligence tools for Windows 10/11,
one for every kind of clue: a nickname, a photo, a domain, a wallet, a company.
Public data only, no accounts, portable builds.


## The list

- **Acid Test** — Check a shop or site before you pay — 23 checks, one plain answer. · [download](https://awesomeosint.tools/acid-test) `site-checker`
- **Aka** — Every public mention of a nickname, year by year, back to the first one. · [download](https://awesomeosint.tools/aka) `username-search`
- **Amber** — Web archive viewer that shows what a page removed. · [download](https://awesomeosint.tools/amber) `web-archive`
- **Assay** — Crypto address reputation: sanctions, mixers, theft reports in one score. · [download](https://awesomeosint.tools/assay) `crypto-aml`
- **Azimuth** — Find where a photo or video was taken from shadows, signs, skylines. · [download](https://awesomeosint.tools/azimuth) `geolocation`
- **Domesday** — Public asset and property records for due diligence. · [download](https://awesomeosint.tools/domesday) `asset-records`
- **Exposure** — See what the internet has on you, then close each trace. · [download](https://awesomeosint.tools/exposure) `digital-footprint`
- **Gazette** — Company and officer search across public registers of many countries. · [download](https://awesomeosint.tools/gazette) `company-search`
- **Interchange** — Follow crypto across chains and name every bridge on the route. · [download](https://awesomeosint.tools/interchange) `cross-chain`
- **Legwork** — AI investigator that answers with a source on every sentence. · [download](https://awesomeosint.tools/legwork) `ai-investigator`
- **Loupe** — Check if a photo or video is edited, recycled or AI-made. · [download](https://awesomeosint.tools/loupe) `image-verification`
- **Mutuals** — See how two accounts are connected, ranked by closeness. · [download](https://awesomeosint.tools/mutuals) `social-graph`
- **Namesake** — Find the right person behind a shared name. · [download](https://awesomeosint.tools/namesake) `people-search`
- **Pegboard** — One clue in, a finished OSINT case out — the family runner. · [download](https://awesomeosint.tools/pegboard) `toolkit`
- **Playtime** — A nickname's gaming profiles and hours on one shelf. · [download](https://awesomeosint.tools/playtime) `gaming-profiles`
- **Redstring** — Accounts, domains and wallets on one board with a string per link. · [download](https://awesomeosint.tools/redstring) `link-analysis`
- **Shamus** — An OSINT agent that lives in your terminal. · [download](https://awesomeosint.tools/shamus) `cli-agent`
- **Spout** — Whale alerts: watch the largest wallets move before the headlines. · [download](https://awesomeosint.tools/spout) `whale-alerts`
- **Strata** — Domain and infrastructure recon, layer by layer. · [download](https://awesomeosint.tools/strata) `domain-recon`
- **Tagless** — Strips metadata from every file you share, from the tray. · [download](https://awesomeosint.tools/tagless) `privacy`
- **Tremor** — Event monitoring from open sources before it is a headline. · [download](https://awesomeosint.tools/tremor) `event-monitor`
- **Whorl** — Wallet behaviour analysis: clustering by shape, not balance. · [download](https://awesomeosint.tools/whorl) `wallet-analysis`

## The idea

Say what you have — a nickname, a photo, a domain — and pick the tool that starts from it.
Every tool runs on Windows, reads only public sources and writes a report you can cite.
No suites, no dashboards: one clue in, one case out.

## Acid Test

![Acid Test](assets/acid-test.png)

Runs 23 checks on a shop, a site or a project and tells you in plain words whether to trust it: five verdicts from "Trust it" to "Walk away", with the evidence behind every check. [Open the site](https://awesomeosint.tools/acid-test/)

## Aka

![Aka](assets/aka.png)

Finds every public mention of a nickname, year by year, back to the first one — and the other names the same person went by on the way. [Open the site](https://awesomeosint.tools/aka/)

## Amber

![Amber](assets/amber.png)

A time machine for web pages: move through saved copies from public archives and see exactly what was removed or changed. [Open the site](https://awesomeosint.tools/amber/)

## Assay

![Assay](assets/assay.png)

## Azimuth

![Domesday](assets/domesday.png)

## Exposure

## Gazette
