# Fieldkit: awesome OSINT tools for Windows

A curated list of the Fieldkit family — open-source intelligence tools for Windows 10/11,
one for every kind of clue: a nickname, a photo, a domain, a wallet, a company.
Public data only, no accounts, portable builds.

> Every tool has its own page and a download link.

## The list

- **Acid Test** — Check a shop or site before you pay — 23 checks, one plain answer. · [download](https://awesomeosint.tools/acid-test/download) `site-checker`
- **Aka** — Every public mention of a nickname, year by year, back to the first one. · [download](https://awesomeosint.tools/aka/download) `username-search`
- **Amber** — Web archive viewer that shows what a page removed. · [download](https://awesomeosint.tools/amber/download) `web-archive`
- **Assay** — Crypto address reputation: sanctions, mixers, theft reports in one score. · [download](https://awesomeosint.tools/assay/download) `crypto-aml`
- **Azimuth** — Find where a photo or video was taken from shadows, signs, skylines. · [download](https://awesomeosint.tools/azimuth/download) `geolocation`
- **Domesday** — Public asset and property records for due diligence. · [download](https://awesomeosint.tools/domesday/download) `asset-records`
- **Exposure** — See what the internet has on you, then close each trace. · [download](https://awesomeosint.tools/exposure/download) `digital-footprint`
- **Gazette** — Company and officer search across public registers of many countries. · [download](https://awesomeosint.tools/gazette/download) `company-search`
- **Interchange** — Follow crypto across chains and name every bridge on the route. · [download](https://awesomeosint.tools/interchange/download) `cross-chain`
- **Legwork** — AI investigator that answers with a source on every sentence. · [download](https://awesomeosint.tools/legwork/download) `ai-investigator`
- **Loupe** — Check if a photo or video is edited, recycled or AI-made. · [download](https://awesomeosint.tools/loupe/download) `image-verification`
- **Mutuals** — See how two accounts are connected, ranked by closeness. · [download](https://awesomeosint.tools/mutuals/download) `social-graph`
- **Namesake** — Find the right person behind a shared name. · [download](https://awesomeosint.tools/namesake/download) `people-search`
- **Pegboard** — One clue in, a finished OSINT case out — the family runner. · [download](https://awesomeosint.tools/pegboard/download) `toolkit`
- **Playtime** — A nickname's gaming profiles and hours on one shelf. · [download](https://awesomeosint.tools/playtime/download) `gaming-profiles`
- **Redstring** — Accounts, domains and wallets on one board with a string per link. · [download](https://awesomeosint.tools/redstring/download) `link-analysis`
- **Shamus** — An OSINT agent that lives in your terminal. · [download](https://awesomeosint.tools/shamus/download) `cli-agent`
- **Spout** — Whale alerts: watch the largest wallets move before the headlines. · [download](https://awesomeosint.tools/spout/download) `whale-alerts`
- **Strata** — Domain and infrastructure recon, layer by layer. · [download](https://awesomeosint.tools/strata/download) `domain-recon`
- **Tagless** — Strips metadata from every file you share, from the tray. · [download](https://awesomeosint.tools/tagless/download) `privacy`
- **Tremor** — Event monitoring from open sources before it is a headline. · [download](https://awesomeosint.tools/tremor/download) `event-monitor`
- **Whorl** — Wallet behaviour analysis: clustering by shape, not balance. · [download](https://awesomeosint.tools/whorl/download) `wallet-analysis`

## The idea

Say what you have — a nickname, a photo, a domain — and pick the tool that starts from it.
Every tool runs on Windows, reads only public sources and writes a report you can cite.
No suites, no dashboards: one clue in, one case out.

## Contributing

One tool per problem, public data only, Windows-first. PRs welcome — a tool joins the
list when it has a working build, a README and a licence.
